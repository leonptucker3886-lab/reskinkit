# ReskinKit v0.1 (beta)
Theme kit for the Spec Op Worklog Board: 4 themes (Midnight, Paper, Neon, Forest). Each changes colors, fonts and layout through CSS variables in `themes.css`.
- `index.html`: landing page with all themes side by side
- `app.html`: the app, with a theme dropdown saved to localStorage (`?theme=` previews a theme without saving it)
Static site, no build step. Deployed on Vercel.
